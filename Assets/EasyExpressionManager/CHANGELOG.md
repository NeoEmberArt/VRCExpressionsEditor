# Changelog

## 2.3.1

- Added native menu moves and sibling ordering without requiring VRCFury.
- Added safer shared-menu edits and native menu capacity checks.
- Improved snapshot validation, reference restoration, and recovery safeguards.
- Improved structure import/export for duplicate items and escaped menu names.
- Fixed operation cancellation, failed mutations, and dissolve snapshot handling.
- Improved VRCFury scanning and protection for unsupported legacy features.
- Kept project Data outside the package and VRCFury optional.

## 2.3.0

- Converted Easy Expression Manager to a VPM-compatible Unity package.
- Added outline-only auto icons with custom outline thickness.
- VRCFury remains optional; native VRChat expression menus work without it.
